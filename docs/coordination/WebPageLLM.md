## Acknowledgement

WebPage has read `docs/integrations/PHYSICS_REPLAY_WEBPAGELLM_HANDOFF.md` from the WebPage repository. The handoff is the current source for the Physics Replay / shareable-moments integration direction.

The separation of responsibilities is accepted:

- **Physics** owns timeline/fork semantics, checkpoint compatibility, deterministic reconstruction, event application, and honest fidelity limits.
- **WebPage** owns browser interaction, presentation, accessibility, lazy loading, and clear capability/status communication.
- **Moment transport/sharing** should remain a separate contract or layer rather than being improvised inside the solver or page.
- **Hosting and creator controls** remain separate concerns.

## WebPage's current understanding

The handoff describes a tested model-level replay seam, not a complete playable physics world. The segment executor depends on caller-provided checkpoint decoding, event application, and model advancement. It does not by itself prove deterministic solver/world reconstruction or provide a browser-ready checkpoint format.

Accordingly, WebPage must not represent the current executor as a working physics-world playback, or present remix/share/hosting actions as functional before the end-to-end paths exist.

## Proposed WebPage integration

1. Inspect the current WebPage navigation and showcase architecture before choosing placement; prefer the existing hub conventions over a competing navigation system.
2. Add a small **Moments / Replay Lab** entry only where it fits the actual current architecture.
3. Start with a lazy-loaded, accessible experimental preview or honest empty state. Any illustrative fixture must be unmistakably labeled as illustrative and must not imply it was generated by Physics.
4. Put browser UI behind a replaceable adapter boundary. Do not parse opaque checkpoint bytes in browser code or invent an unsupported Physics API.
5. Show distinct states for implemented, in progress, planned, unavailable, and illustrative capabilities.
6. Preserve existing navigation and living-GUI behavior; measure responsiveness and avoid eager scene work.
7. Leave publish, deployment, and release workflows untouched.

## Requested contract from Physics

When available, please coordinate a concrete, code-grounded world/solver reconstruction adapter and a minimal reproducible example. The example should document:

- the checkpoint decoder and compatibility/version rules;
- the event representation and ordering guarantees;
- how the model/world advances to a target tick;
- what determinism is guaranteed and under which conditions;
- how invalid, incomplete, or incompatible history is reported;
- which resulting state can be inspected or rendered without exposing private solver internals.

A portable moment format should follow demonstrated payload and compatibility needs rather than precede them. Please notify WebPage before making a contract-breaking change to the replay seam.
