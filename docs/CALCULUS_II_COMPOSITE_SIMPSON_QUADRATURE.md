# Calculus II — Measuring Accumulation with Numerical Quadrature

**Status:** Implemented bounded composite Simpson quadrature with focused analytical-reference tests. A refined estimate reports an asymptotic correction indicator, not a rigorous error bound. No adaptive integrator or automatic unit system is claimed.

## 01 — What: an integral accumulates local contributions

A definite integral adds up a function's contributions across an interval. If a function describes velocity over time, its integral describes displacement. If it describes a cross-sectional height along a horizontal coordinate, its integral describes signed area.

\[
I=\int_a^b f(x)\,dx
\]

The sign follows the integration direction: reversing the bounds negates the result. A zero-width interval has zero integral. Units multiply: output units times input-coordinate units.

## 02 — Why: many useful models have no convenient antiderivative

A physical model may be available only as a function evaluator. It may be expensive, generated by another subsystem, or defined by a numerical procedure. Quadrature estimates the accumulated quantity from a finite set of samples.

The simplest rectangle and trapezoid rules approximate the function with constant or linear pieces. Simpson's rule uses parabolic pieces over pairs of equal-width subintervals. For smooth functions, this captures curvature and has fourth-order global truncation error as the grid is refined.

## 03 — How: composite Simpson's rule and refinement

For an even number \(n\) of equal subintervals, let \(h=(b-a)/n\) and \(x_i=a+ih\). Composite Simpson's rule is

\[
S_n=\frac{h}{3}\left[f(x_0)+4\sum_{i\;\mathrm{odd}}f(x_i)+2\sum_{i\;\mathrm{even},\;0<i<n}f(x_i)+f(x_n)\right].
\]

The interval count must be positive and even. This implementation caps the refined grid at one million subintervals so a caller cannot accidentally request unbounded work through this API. It evaluates samples in order, rejects repeated or non-finite coordinates, rejects non-finite function samples, and checks weighted accumulation and the final result for overflow.

For a sufficiently smooth function in the asymptotic regime, the leading Simpson error is proportional to \(h^4\). Halving the step reduces that leading term by approximately sixteen. If \(S_n\) is the coarse result and \(S_{2n}\) is the refined result, Richardson extrapolation gives

\[
I_{\mathrm{R}}=S_{2n}+\frac{S_{2n}-S_n}{15}.
\]

The magnitude of the correction is returned as an **estimated absolute error indicator**. It is not a rigorous bound. Nonsmooth functions, unresolved narrow features, discontinuities, or roundoff-dominated calculations can invalidate the asymptotic model. The caller remains responsible for choosing an interval count appropriate to the function.

The function is evaluated independently on the coarse and fine grids. It should be deterministic and side-effect free. The API does not infer units, discover singularities, adaptively place samples, or promise convergence for arbitrary functions.

## 04 — See it in a minute: integrate a known function

For \(f(x)=x^3-2x+4\) on \([-1,2]\), the exact integral is \(12.75\). Simpson's rule integrates every cubic exactly in exact arithmetic:

\[
\int_{-1}^{2}(x^3-2x+4)\,dx=12.75.
\]

~~~csharp
using TheSingularityWorkshop.Physics.Numerics;

double area = Quadrature.CompositeSimpson(
    x => (x * x * x) - (2d * x) + 4d,
    lowerBound: -1d,
    upperBound: 2d,
    intervalCount: 8);

IntegralEstimate refined =
    Quadrature.CompositeSimpsonWithErrorEstimate(
        Math.Exp,
        lowerBound: 0d,
        upperBound: 1d,
        intervalCount: 4);

Console.WriteLine(area);
Console.WriteLine(refined.Value);
Console.WriteLine(refined.EstimatedAbsoluteError);
~~~

The focused tests cover a cubic polynomial with a closed-form integral, the sine integral on \([0,\pi]\), reversed bounds, zero-width intervals, invalid bounds and interval counts, non-finite samples, arithmetic overflow, refinement against the exact exponential integral, and the expected independent coarse/fine evaluation count.

**Evidence classification:** implemented numerical primitive with focused automated tests and analytical reference identities. The tests establish these bounded cases; they do not prove convergence for arbitrary integrands or turn the correction indicator into a guaranteed error bound. There is not yet a generated integration run record or living area visualization.
